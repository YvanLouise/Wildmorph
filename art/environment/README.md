# 草原场景道具集 1

本目录新增 36 张保留透明通道的 PNG 原图。素材按玩法用途分类，未修改尺寸、颜色或像素内容。

| 分类 | 数量 | 内容 |
| --- | ---: | --- |
| `trees/` | 4 | 阔叶树、针叶树、圆冠树、幼树 |
| `wood/` | 3 | 原木、树桩、树枝 |
| `rocks/` | 9 | 4 块岩石、5 颗石子 |
| `vegetation/` | 9 | 灌木、草、野花、叶片、芦苇、蘑菇 |
| `food/` | 3 | 火腿、苹果、肉排 |
| `terrain/` | 3 | 土堆、枯枝堆、地洞 |
| `landmarks/` | 3 | 池塘、洞穴、鸟巢 |
| `remains/` | 2 | 头骨、骨头 |

## 命名约定

- 使用 `对象名-三位变体序号.png`，例如 `岩石-005.png`。
- `岩石-005` 至 `岩石-008` 延续现有 `art/environment/石头-001` 至 `石头-004` 的编号，不覆盖已有文件。
- 素材仅已归档；需要在游戏中使用时，再在 `src/game/assets/manifest.ts` 中注册。

## 接入约定

- 运行时使用的资源统一登记在 `src/game/assets/manifest.ts`，业务代码不直接散布文件路径。
- 新角色放入 `characters/`，地图物件放入 `environment/`，界面资源放入 `ui/` 的对应子目录。
- 保留透明 PNG 原图；导出优化版时使用新文件，不覆盖源文件。
- 新文件名应包含对象名称和变体编号，例如 `石头-005.png`。
